# counter_reading_prompt.md — Counter-Reading (반론 생성) 프롬프트

## 역할

Claude가 자신의 분석에 대해 스스로 반론을 생성한다.
"반론을 먼저 찾는다" 원칙의 실행 도구.
이 Pass는 생략할 수 없다.

---

## 시스템 프롬프트

```
당신은 지금 악마의 변호인(Devil's Advocate) 역할을 맡습니다.
주어진 설교 연구 보고서의 주요 해석에 대해
가장 강력한 반론을 생성하세요.

중요:
- 이 반론 생성은 분석을 강화하기 위한 것입니다
- 최종적으로 반론을 수용할지 여부는 설교자가 결정합니다
- 반론은 학문적으로 진지해야 합니다 (억지 반박 금지)
- 각 반론에 "이 반론의 강도"를 평가합니다
```

---

## Counter-Reading 8개 관점

```yaml
counter_reading_perspectives:
  CR-1:
    name: "대안 해석"
    question: "이 본문에 대해 학문적으로 인정받는 다른 해석이 있는가?"
    probe: "어떤 주석가가 다른 해석을 제시하는가? 그 근거는?"

  CR-2:
    name: "문맥 반론"
    question: "이 해석이 직전·직후 문맥과 실제로 일치하는가?"
    probe: "인접 절들이 이 해석에 도전하는 내용을 담고 있지는 않은가?"

  CR-3:
    name: "원어 반론"
    question: "원어 분석이 다른 번역이나 뜻을 허용하는가?"
    probe: "핵심 단어의 semantic range에서 놓친 의미가 있는가?"

  CR-4:
    name: "역사 반론"
    question: "역사·문화 배경 해석이 과잉 단순화되지 않았는가?"
    probe: "1세기 맥락에서 이 해석이 실제로 통했을까?"

  CR-5:
    name: "그리스도 연결 반론"
    question: "이 그리스도 연결이 실제로 본문 논리에서 나오는가, 아니면 신학 체계를 소급 적용한 것인가?"
    probe: "연결 논리를 제거해도 본문이 독립적으로 의미를 갖는가?"

  CR-6:
    name: "적용 반론"
    question: "이 적용이 오늘 성도의 실제 삶에서 작동하는가?"
    probe: "이 적용이 율법주의나 값싼 은혜로 흐를 위험이 있는가?"

  CR-7:
    name: "설교자 편향 반론"
    question: "설교자가 자신의 기존 신학 입장을 확인하기 위해 본문을 읽지는 않았는가?"
    probe: "본문이 설교자의 기대와 다른 방향을 가리키는 신호가 있는가?"

  CR-8:
    name: "청중 반론"
    question: "이 설교를 들을 청중이 이 해석에 합리적인 의문을 제기할 수 있는가?"
    probe: "청중이 '그게 정말 본문이 말하는 건가요?'라고 물을 수 있는 지점이 있는가?"
```

## Counter-Reading 출력 형식

```markdown
# Counter-Reading 보고서 — {passage}

생성일시: {timestamp}
분석된 주요 해석: {main_interpretation_summary}

---

## CR-1: 대안 해석

**반론 강도**: 🔴 강 | 🟡 중 | 🟢 약

**반론 내용**:
{counter_argument}

**근거**:
{evidence_for_counter}

**설교자 응답 옵션**:
- A) 반론 수용 → 해석 수정
- B) 반론 인정하되 기존 해석 유지 → 설교에서 "다른 학자는 ~라고 보기도 합니다" 언급
- C) 반론 기각 → 기각 근거: {reason}

---
```

## 반론 강도 기준

| 강도 | 정의 |
|------|------|
| 🔴 강 | 학문적으로 유력한 반론. 반드시 설교에서 언급하거나 해석 수정 필요 |
| 🟡 중 | 일부 학자가 지지하는 반론. 인정은 하되 기존 해석 유지 가능 |
| 🟢 약 | 개연성 낮은 반론. 기각해도 무방하나 기각 근거 명시 권고 |

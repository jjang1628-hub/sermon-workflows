## Pass 1–3: 본문 기초

### Pass 1: 본문 경계 확인

요한복음 13:14는 독립적 구절이 아니라 **13:1–17 세족식 내러티브**의 해석부(13:12–17)에 속한다.

- **사건부**: 13:1–11 — 예수님의 세족 행위 자체
- **해석부**: 13:12–17 — 예수님이 직접 그 의미를 설명하심
- **14절의 위치**: 13절(칭호 확인) → **14절(역전 논증)** → 15절(ὑπόδειγμα 선언) → 16절(종·주인 격언) → 17절(복 선언)

13:1–17은 고별 담화(13–17장)의 서두이며, 배신 예고(21–30절)와 새 계명(34–35절)으로 이어지는 사랑의 실천 단락이다. 14절은 그 단락의 **논증 중심절**이다.

**🔵 경계 신뢰도: 높음**

### Pass 2: 문학 장르 분류

- **거시 장르**: 복음서 내러티브 (요한복음)
- **미시 장르**: 행동-해석 단위 (Zeichenhandlung + Deutewort) — 예언자적 상징 행동 + 해석 말씀
- **수사 형식**: *a fortiori* (더 큰 것에서 더 작은 것으로) 논증 — "주와 선생인 내가 씻겼으니, 너희도 씻겨야 한다"
- **유대 배경**: 고별사 장르(Testament Genre) — 죽음 전 마지막 유언적 가르침 (Bammel, 1993)
- **요한 특유의 기법**: 오해 → 설명 → 더 깊은 이해 (cf. 13:6–10 베드로의 오해 → 정정)

**🔵 장르 신뢰도: 높음**

### Pass 3: 본문 구조 분석

```
13:1   서두 — εἰς τέλος 사랑의 선언 (전체 단락 주제)
  │
13:2–5  사건 도입 — 유다의 배신 예정 + 예수의 자기 인식(13:3) + 세족 행위
  │
13:6–11  베드로와의 대화 — 오해·거부·수용·씻김의 의미(13:8 구원론적 핵심)
  │
13:12–17 ← 해석 단락 (14절이 여기 속함)
  ├─ 13:12 "내가 너희에게 행한 것을 아느냐?" — 재좌정 후 질문
  ├─ 13:13 "너희가 나를 선생·주라 하니 옳도다" — 칭호 확인
  ├─ 13:14 ★ "내가 씻겼으니 너희도 씻겨야 한다" — 역전 논증 (핵심절)
  ├─ 13:15 "ὑπόδειγμα를 보였노라" — 본(pattern) 선언
  ├─ 13:16 종·주인 격언 — 16:20; 마 10:24 병행
  └─ 13:17 "이것을 알고 행하면 복이 있다" — 종결 복 선언
```

**14절의 논증 구조**:

> **완료 indicative** → **현재 imperative**
> "씻었으니(완료, 선행 사실)" → "씻어야 한다(현재, 파생 의무)"

이것이 요한복음 13장의 **은혜→순종 구조**의 중추이다.

**🔵 구조 신뢰도: 높음**

### Pass 5: 원어 심층 분석

#### 1. νίπτω (nipto) vs. λούω (louō) — 씻김의 두 층위 🔵

요한복음 13장에서 두 단어는 의도적으로 구별된다:

- **λούω** (louō, 13:10) — 전신 목욕. 요한복음에서 중생/구원적 정결의 언어
  - "이미 목욕한 자(λελουμένος)는 발밖에 씻을 필요가 없다"
  - = 이미 예수 안에서 구원받은 자는 완전히 깨끗함

- **νίπτω** (niptō, 13:5,6,8,10,12,14) — 부분 씻음. 지속적 정결의 언어
  - 13:8의 결정적 구원론적 선언: "내가 너를 씻어 주지(νίψω) 아니하면 네가 나와 상관(μέρος)이 없느니라"
  - μέρος = 몫, 분깃, 관계 → 씻김 거부 = 예수와의 구원적 관계 단절

**신학적 함의**: 13:14의 "너희도 서로 발을 씻어 주어야 한다(νίπτειν)"는 단순한 위생적·겸손적 행위가 아니다. 예수님이 하신 씻김(구원적 정결)을 공동체가 상호 실천하는 것이다. 제자들 사이의 용서·섬김·화해가 신학적으로 νίπτω의 언어로 표현된다.

#### 2. ὀφείλετε (opheilete) — 의무의 언어 🔵

- 단순 권유(δεῖ, should)가 아닌 **도덕적 채무(ought, must)** 언어
- 요한 문헌 내 동일 단어 사용: 요일 3:16 "우리가 형제들을 위하여 목숨을 버리는 것이 **마땅하니라(ὀφείλομεν)**"
  - 요일 3:16의 논리: "그리스도가 우리를 위해 목숨을 버리셨기에(indicative) → 우리도 마땅히 목숨을 버려야 한다(imperative)"
  - **13:14와 구조 동일**: 먼저 받은 은혜가 의무의 근거

**핵심**: ὀφείλετε는 외부에서 부과된 규칙이 아니라, **받은 은혜에서 내부적으로 흘러나오는 필연**이다. 이것이 요한 공동체의 윤리 구조다.

#### 3. εἰς τέλος (13:1) — 서두의 신학적 틀 🟡

- 직역: "끝까지" (to the end) 또는 "완전히/극치까지" (to the uttermost)
- τέλος = 끝 + 완성 + 극치 (BDAG) — 두 의미가 동시에 작동
- 13:14는 이 εἰς τέλος 사랑의 구체적 행동 표현
- 세족식 → 십자가로 이어지는 "끝까지의 사랑" 첫 번째 육화(embodiment)

**🟡 해석 주의**: εἰς τέλος를 "죽음까지"로만 읽으면 십자가와 연결되지만, "완전히/온전히"로 읽으면 사랑의 질을 강조. 두 해석 모두 신학적으로 정당하며 상호 보완적.

### Pass 6: 역사·문화 배경 🔵

**유대 전통에서 발 씻기의 위치**:
- 바벨론 탈무드(b. Ketub. 96a): "제자는 스승의 발을 씻기지 않는다" — 이것은 이방인 종(slave)의 일
- 유대인 종도 스승의 발을 씻기지 않는 것이 관례
- 예수님이 스스로 제자들의 발을 씻기신 것은 **당시 문화에서 최하위 섬김자의 자리**를 자발적으로 취하신 것

**헬레니즘 배경**:
- 그리스·로마 세계에서도 발 씻기는 노예의 일
- 연회(δεῖπνον) 자리에서 주인이 종들의 발을 씻기는 것은 사회적 전복
- 예수님의 행동은 당시 청중에게 **충격적인 권위의 역전**으로 읽혔을 것

**유월절 전날 밤의 맥락**:
- 13:1 "유월절 전에" — 출애굽의 해방과 구속 기념 절기 직전
- 같은 식탁에서 배신자 예고(21–30절) — 배신과 섬김이 동시에 일어나는 자리
- "끝까지 사랑하시되" — 배신을 아시면서도 씻기심

### Pass 7: 문학적 흐름 🔵

요한복음 13장의 논증 전개:

1. **13:1** — 신학적 서두: εἰς τέλος 사랑 (왜 씻기시는가의 배경)
2. **13:3** — 자기 인식: "아버지께서 모든 것을 자기 손에 맡기신 줄 알고... 하나님께로부터 오셨다가 돌아가시는 것을 아시고" — **정체성의 확고함**이 낮아짐의 근거
3. **13:4–5** — 행동: 의복을 벗으심 + 수건을 두르심 + 물을 부음 + 발을 씻기심
4. **13:6–11** — 베드로와의 신학적 대화: 씻김의 구원론적 의미 (13:8 μέρος)
5. **13:12–17** — 해석: "내가 행한 것을 아느냐?" → 14절 역전 논증 → 15절 ὑπόδειγμα

저자 요한의 의도: 세족식을 **십자가의 예행연습(proleptic embodiment)**으로 제시하고, 그 사랑의 패턴이 공동체에서 지속되어야 함을 가르침.

## Pass 8–11: 저자·독자·구속사

### Pass 8: 저자 의도 🔵

요한은 세족식을 단순한 겸손 교훈으로 제시하지 않는다. 그의 의도는 **다층적**이다:

1. **구원론적 층위**: 13:8의 씻김 = 예수님의 정결케 하는 구원 사역. 발 씻기는 십자가 죽음의 상징적 선행 행위
2. **윤리적 층위**: 13:14–15의 ὑπόδειγμα = 공동체의 상호 섬김 패턴. 받은 은혜가 섬김의 동기
3. **기독론적 층위**: 13:3의 자기 인식에서 낮아지심 = 십자가 케노시스(빌 2:5–8)와 동일한 신학적 구조

저자는 제자들(원독자들)이 **자신들이 이미 씻김을 받았다는 사실**을 기억하며 서로를 섬기기를 원한다.

### Pass 9: 원독자 상황 🟡

요한 공동체(소아시아, 1세기 말 추정)의 맥락:
- 회당 추방 이후 경험 — 사회적 소외와 공동체 내 긴장
- "서로 사랑하라"(13:34–35)는 새 계명이 공동체 정체성의 핵심
- 발 씻기 실천이 초대 교회 예배/환대 관습으로 이어짐 (딤전 5:10 성도들의 발 씻김)
- 원독자들에게 13:14는 **교회 공동체의 삶 방식**을 가르치는 구절로 들렸을 것

**🟡 주의**: 요한 공동체의 구체적 상황은 학자마다 다르게 재구성됨. 확정적 진술 자제.

### Pass 10: 구속사적 위치 🔵

```
창조 — 하나님의 형상으로 지음받은 인간 (섬김과 돌봄의 소명)
  ↓
타락 — 섬김 대신 지배, 씻김 대신 오염, "상관" 단절
  ↓
구속 — 예수님의 세족 + 십자가: 씻김·정결·관계 회복 (13:8, 14)
  ↓
새창조 — 씻김 받은 공동체가 서로 씻기는 새로운 사회 패턴 (13:14–15, 34–35)
```

요한복음 13:14는 **구속이 공동체에서 가시화되는 지점**이다. 예수님이 하신 씻김(구속)이 제자들의 상호 섬김(새창조의 삶)으로 이어진다.

### Pass 11: 그리스도 연결 논리 🔵

**억지 알레고리 없이 본문 내부에서 자연스럽게 가리키는 그리스도의 사역**:

1. **13:8 → 십자가**: "씻어 주지 않으면 나와 상관이 없다" — 예수님의 씻김 없이는 관계 없음 = 십자가 없이는 구원 없음
2. **13:1 → 완성**: "εἰς τέλος 사랑" — 세족식에서 시작해 십자가에서 완성됨 (19:30 "τετέλεσται" 완성되었다)
3. **13:3 → 성육신 케노시스**: "아버지께로부터 오셔서" — 빌 2:6–8과 동일한 신학 구조
4. **13:14 → 칭의 근거**: "씻었으니 씻어야" — indicative가 imperative의 근거. 그리스도의 사역(indicative)이 성도의 삶(imperative)의 기초

**주석 간 주요 긴장점**: 세족식이 성례전적 의미를 갖는가(세례/성만찬과 연결)?
- Brown: 세례와의 연결 가능성 제기

- **판단**: 성례전 연결은 과도한 해석 위험. 구원론적 상징 + 공동체 패턴으로 읽는 것이 본문에 더 충실.

### Pass 13: 신학 주제 🔵

**핵심 신학 주제: 은혜–섬김의 논리 구조 (indicative–imperative)**

요한복음 13:14는 바울 서신의 indicative–imperative 구조와 동일한 신학적 패턴을 요한의 방식으로 표현한다:

- 바울 (롬 12:1): "하나님의 자비로 인하여(indicative) 몸을 드리라(imperative)"
- 요한 (13:14): "내가 씻겼으니(indicative) 너희도 씻겨야 한다(imperative)"

이것은 도덕주의(imperative만 있음)도 아니고, 은혜주의(indicative만 있음)도 아닌 **복음적 윤리** 구조다. 명령의 근거는 규칙이 아니라 받은 사랑이다.

**부수 신학 주제**:
1. **케노시스의 자발성** (13:3): 자신의 기원과 목적지를 아는 자의 자유로운 낮아짐
2. **공동체 상호성** (ἀλλήλων): 위계가 아닌 상호 섬김 — 일방적 섬김자/피섬김자 구도 해체
3. **ὑπόδειγμα (패턴)**: 일회성 예시가 아닌 지속적 공동체 패턴

### Pass 14: 교리적 함의 🔵

**교의학 (하나님 지식의 체계)**:
- 기독론: 성육신의 목적 = 섬기러 오심 (막 10:45와 수렴). 13:3의 자기 인식 = 높은 기독론적 자의식
- 구원론: 13:8 — 씻김 없이 관계 없음 = 그리스도의 사역 없이 구원 없음
- 성령론/적용: 씻김 받은 자 안에서 성령이 이 사랑을 동기로 활성화

**윤리학 (하나님 봉사의 체계)**:
- 섬김의 동기: 외부적 규칙 준수가 아니라 내부적 감사·은혜 응답
- 교회론: ἀλλήλων(서로) 공동체 — 목사만 섬기는 교회가 아닌, 서로가 서로를 씻기는 교회
- 직제 비판: 교회의 권위 구조가 세상의 지배 구조를 닮으면 안 됨 (막 10:42–45 병행)

**교리 없는 윤리 위험 진단**:
- "주님처럼 섬기자"는 복음적 indicative 없이는 도덕주의로 전락
- 13:14를 "섬겨야 한다"는 명령만으로 설교하면 율법적 설교
- 반드시 13:8의 "씻어 주심"(그리스도의 구속)이 먼저 와야 함

## Pass 16: 반론 및 대안 해석

### 대안 해석 1: 세족식을 세례와 연결하는 해석 🟡

**주장**: 13:10의 λούω(목욕)는 세례를 가리키며, 세족식은 성례전 행위다.
**근거**: Brown, Schnackenburg 등이 제기. 세례 받은 자도 지속적 정결 필요(νίπτω).
**반론**: 본문에 세례 언급 없음. 요한복음은 성례전보다 예수 자신에게 집중. Carson, Keener는 과도한 성례전화 경계.
**판단**: 세례 상징을 완전히 배제할 수는 없으나, 설교의 주 해석선으로 삼기엔 본문 근거 약함.

### 대안 해석 2: 세족식을 문자적 교회 관습으로만 이해하는 해석 🔴

**주장**: 13:14은 교회 예배에서 실제로 발을 씻겨야 하는 지시다(일부 아나뱁티스트 전통).
**근거**: 딤전 5:10에서 초대 교회 관습으로 보임. 문자적 명령으로 읽음.
**반론**: 15절 "본(ὑπόδειγμα)"은 반복적·패턴적 성격을 강조. 단순 의식화보다 삶의 태도와 공동체 섬김이 요점. 요한복음 전체의 상징적 언어 사용과도 부합.
**판단**: 문자적 관습으로 축소하면 본문의 신학적 깊이를 잃음. 다만 실제 봉사 실천도 배제 안 됨.

### 반론: "이 설교는 도덕주의 설교가 될 위험이 있다" 🔴

**진단**: 13:14를 단독으로 다루면 "섬겨라!" 도덕 훈계가 됨.
**해결**: 13:8의 구원론적 씻김(indicative)이 반드시 선행되어야 함. 구조:
  1. 예수님이 먼저 씻기셨다 (구속론 — 왜 씻기셨는가: 13:1, 3, 8)
  2. 씻김 받은 우리 (응용 — 우리가 이미 받은 것)
  3. 씻기는 우리 (결과 — 받은 은혜가 흐름)

## Pass 17–19: 설교 설계

### Pass 17: 현대 적용 원리 🔵

**복음적 적용 원리** (도덕주의 위험 방어):

1. **"씻기심을 받은 자만이 씻길 수 있다"** — 은혜 경험이 섬김의 자원. 은혜 없는 섬김은 소진(burnout)으로 끝남
2. **"정체성이 확고할 때 낮아질 수 있다"** (13:3) — 베드로처럼 인정 욕구가 강한 사람은 섬기기 힘듦. 예수님은 "아버지께서 모든 것을 맡기셨다"는 확신에서 씻기심
3. **"권위가 높을수록 섬겨야 하는 이유가 더 많다"** — 13:13–14 논증 구조. 목사이기에, 부모이기에, 리더이기에 더 낮아지라
4. **"섬김을 받는 것도 훈련이다"** — 13:6–9 베드로의 거부. 내가 섬김 받기를 거부하는 것은 어떤 교만인가?
5. **"서로(ἀλλήλων) — 공동체 전체의 패턴"** — 섬김이 특정인의 번아웃이 아닌 순환하는 공동체 문화

### Pass 18: 설교 Big Idea (한 문장) 🔵

> **"주님이 먼저 우리를 씻겨 주셨기 때문에, 씻김 받은 우리는 서로를 씻긴다."**

**Big Idea 구조 분석**:
- **하나님께서 하신 일 (indicative)**: 주와 선생이신 예수님이 발을 씻기심
- **우리의 반응 (imperative)**: 서로 씻기는 공동체
- **복음 선언 형식**: "때문에" — 먼저 받은 은혜가 근거

**대안 Big Idea** (비교):
- NG: "섬기는 자가 진정한 위인이다" — 인본주의, 도덕주의
- NG: "예수님처럼 겸손해야 한다" — 도덕적 모방, 복음 결여
- OK: "씻김 받은 자는 씻긴다" — 복음 패턴 명확하나 너무 짧음

### Pass 19: 적용 구조 🔵

```
복음의 은혜 (indicative)
  → 예수님이 먼저 씻기셨다 (13:1, 8)
  → 십자가까지의 끝까지 사랑
  → 이미 나는 씻김 받았다

    ↓ 동기 변화

"그분이 씻기셨으니 나도 씻겨야 한다"
  → 규칙이 아니라 은혜의 논리
  → 정체성이 확고한 자의 자유로운 낮아짐

    ↓ 순종의 열매

서로 씻기는 공동체 (ἀλλήλων)
  → 이번 주 구체적: 내가 씻길 사람 한 명
  → 교회 안에서 순환하는 섬김의 문화
```

## Pass 20: 통합 검토

### 약점 및 주의사항

1. **도덕주의 위험 (최고 위험)**: 13:14만 가져오면 "섬겨라" 훈계로 전락. 반드시 13:1+13:8의 indicative를 먼저 확립할 것 — **설교 구조에서 은혜가 명령보다 앞서야 함**

2. **인물 영웅화 위험**: "예수님처럼 겸손한 사람이 됩시다" 결론은 인물 영웅화. 예수님의 행동을 윤리적 모델로만 읽지 말고 **구원론적 근거**로 먼저 읽어야 함

3. **베드로 사용 주의**: 13:6–9 베드로의 거부를 "잘못된 자세"로 단순 비판하지 말 것. 그의 거부는 예수님의 신분에 대한 경외에서 나옴 — 이해 가능한 반응으로 제시

4. **세족식 신비화 위험**: 발 씻기를 지나치게 신비화하거나 성례전화하면 본문 초점을 잃음

5. **ὀφείλετε 번역 주의**: "옳으니라"(개역개정)는 도덕적 채무 언어를 약화시킴. 설교에서 "해야 한다" "마땅히"로 강도를 살릴 것

## 설교 체득 압축본 (7가지)

### ① 30초 흐름
> 예수님은 주와 선생이시면서도 제자들의 발을 씻기셨다. 그것은 끝까지의 사랑, 십자가까지의 사랑의 첫 번째 몸짓이었다. 씻기심을 받은 우리는 이제 서로를 씻긴다. 은혜가 흐른다.

### ② Big Idea (한 문장)
> 주님이 먼저 우리를 씻겨 주셨기 때문에, 씻김 받은 우리는 서로를 씻긴다.

### ③ 대지별 핵심 문장
1. **권위자가 낮아지셨다**: "주와 선생인 내가 씻겼으니 — 이것이 논리다."
2. **씻기심이 먼저다**: "명령 전에 은혜가 먼저 온다. ὀφείλετε(해야 한다)의 근거는 이미 받은 것이다."
3. **서로 씻기라**: "ἀλλήλων — 일방이 아니라 서로. 교회는 씻기고 씻기는 공동체다."

### ④ 전환 문장
- 서론→본론: "왜 예수님은 이렇게 하셨을까요? 13장 1절이 답입니다."

- 대지 2→3: "은혜를 받은 사람은 그 은혜를 흘려보냅니다. 14절 마지막이 '서로'입니다."

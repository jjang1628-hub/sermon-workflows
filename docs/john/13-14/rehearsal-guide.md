## 리허설 후 수정 원칙

딱 세 종류만 고치십시오.

### 1. 안 읽히는 문장 → 나눈다

```
전: 예수님은 자신이 아버지께로부터 오셨고 다시 아버지께로 돌아가실 것을
    아셨기 때문에 제자들의 발을 씻기실 수 있었습니다.

후: 예수님은 아셨습니다.
    자신이 어디서 왔는지.
    어디로 가는지.
    그래서 낮아지실 수 있었습니다.
```

### 2. 설명이 많은 문장 → 강단 문장으로

```
전: 이 본문은 예수님의 낮아지심이 단순한 윤리적 모범이 아니라
    구속사적 의미를 지닌다는 사실을 보여 줍니다.

후: 예수님의 발 씻김은 단순한 예절이 아닙니다.
    십자가로 가는 사랑의 예고입니다.
```

### 3. 적용이 무거운 문장 → 복음 선언을 앞에

```
전: 우리도 서로의 발을 씻겨야 합니다.

후: 우리는 먼저 씻김 받은 사람입니다.
    그래서 이제 다른 사람의 먼지 앞에서 도망가지 않을 수 있습니다.
```
